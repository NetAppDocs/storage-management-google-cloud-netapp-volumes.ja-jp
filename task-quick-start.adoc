= Google Cloud NetApp Volumes のクイックスタート
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
Google Cloud NetApp Volumes の使用を開始するには、NetApp Console ロールの割り当て、認証情報の追加、およびシステムの検出を行います。

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-1.png["1"] link:task-add-roles.html["役割を割り当てる"]
[role="quick-margin-para"]
NetApp Consoleから、メンバーに適切なロールを割り当てます。

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-2.png["2"] link:https://docs.netapp.com/us-en/data-services-workloads/gcnv/add-credentials.html["クレデンシャルを追加"]
[role="quick-margin-para"]
NetApp Consoleで、Google Cloud NetApp Volumesの認証情報を追加します。

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-3.png["三つ"] link:task-create-system.html["システムを追加する"]
[role="quick-margin-para"]
NetApp Consoleで、認証情報、Google Cloudプロジェクト、およびサポートされているリージョンを使用してシステムを検出します。
