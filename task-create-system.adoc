= Google Cloud NetApp Volumesシステムを追加する
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
サービス アカウントを設定したら、 NetApp ConsoleでGoogle Cloud NetApp Volumesシステムを追加して、 Google Cloud NetApp Volumesインスタンスを表示できるようにします。

このサブスクリプションのクラウド ボリュームがシステムに表示されます。


NOTE: 複数の Google Cloud プロジェクトにサブスクリプションとボリュームがある場合は、プロジェクトごとにこのタスクを実行する必要があります。

.開始する前に
各プロジェクトにシステムを追加する前に、以下の点を確認してください：

* Google Cloudサービスアカウントが設定され、その認証情報がNetApp Consoleで利用可能になっています。詳細については、link:task-set-up-gcnv.html["Google Cloud NetApp Volumesを設定する"]を参照してください。
* NetApp Console で Google Cloud NetApp Volumes の管理者または閲覧者のロールを持っています。詳細については、link:task-add-roles.html["Google Cloud NetApp Volumes のロールを割り当てる"] を参照してください。


.手順
. NetApp Consoleメニューから、*ストレージ* を選択し、次に *管理* を選択します。
. [システム] ページで、[システムの追加] を選択し、[Google Cloud Platform] を選択します。
. * Google Cloud NetApp Volumes* の横にある *Discover* を選択します。
. NetApp Volumes サブスクリプションに関する情報を入力してください。
+
.. 使用するシステム名を入力します。
.. *認証情報* から、使用する Google Cloud NetApp Volumes の認証情報を選択します。
+
認証情報が表示されない場合は、続行する前にGoogle Cloud NetApp Volumesの認証情報を追加してください。認証情報が利用可能になるまで、プロジェクトとリージョンの選択はできません。

.. *リージョン*から、Google Cloud NetApp Volumesでサポートされているリージョンを選択します。
.. *Discover*を選択します。




.結果
コンソールにGoogle Cloud NetApp Volumesシステムが表示されます。
